## 六、风险评估

### 高风险项
1. **OpenRouter/AA 网站结构变化** → 爬虫失效
   - 缓解：健壮的解析逻辑 + 异常处理 + 降级策略

2. **LLM 调用成本超预期** → 预算超支
   - 缓解：使用 deepseek-v4-flash（最便宜）+ 缓存 + 批量处理

3. **开发时间超预期** → 延期
   - 缓解：按优先级分阶段交付，MVP先上线

### 中风险项
4. **交易日历数据不准确** → 逻辑错误
   - 缓解：使用成熟的 exchange-calendars 库

5. **数据源不稳定**（资金流向、爬虫目标）→ 功能失效
   - 缓解：多数据源备选 + 降级策略
