# AI 日报数据问题 - 实施计划

## 📋 AI 日报4个数据问题

### 问题 1: 从新闻中提取 ARR/营收数据
**现状**：新闻中包含重要的营收数据，但未提取
**目标**：LLM 从新闻中提取 ARR、营收、融资等数值指标

### 问题 2: 提取 Token 使用量数据
**现状**：新闻中提到的 Token 调用量未结构化
**目标**：提取各模型的 Token 使用量、调用次数等

### 问题 3: 计算 Token 成本
**现状**：只有价格数据，没有成本分析
**目标**：基于价格和使用量，计算实际成本

### 问题 4: 用户数/活跃度数据
**现状**：用户数、日活、月活等指标未提取
**目标**：从新闻中提取用户相关指标

---

## 🎯 实施方案

### Phase 1: 新闻指标提取器（2-3小时）

#### 步骤 1: 创建指标提取模块（1.5小时）

**文件**：`news_metrics_extractor.py`

功能：
1. LLM 驱动的指标提取
   - ARR/营收（年度/季度）
   - 融资金额/估值
   - 用户数（总用户/日活/月活）
   - Token 使用量（日/周/月）
   - API 调用量
   - 价格变化

2. 结构化输出
   ```json
   {
     "company": "Anthropic",
     "metrics": [
       {
         "type": "ARR",
         "value": 1000000000,
         "currency": "USD",
         "period": "2024-Q3",
         "source_title": "...",
         "confidence": 0.9
       }
     ]
   }
   ```

3. 置信度评估
   - 官方公告：0.9-1.0
   - 媒体报道：0.7-0.8
   - 分析师估计：0.5-0.6

#### 步骤 2: 集成到主流程（0.5小时）

修改 `ai_daily_push.py`：
- 在新闻采集后提取指标
- 存储指标数据
- 传递到 HTML 生成

#### 步骤 3: 更新 HTML 展示（1小时）

新增板块：**📊 行业数据洞察**

展示内容：
1. **官方公布数据**（来自新闻提取）
   - ARR/营收
   - 融资金额
   - 用户数/活跃度
   - Token 使用量

2. **市场价格数据**（来自 OpenRouter）
   - 各模型价格
   - 价格变化趋势

3. **性能基准**（来自 Artificial Analysis）
   - 速度/质量评分
   - 性价比排名

---

### Phase 2: Token 成本计算器（1-2小时）

#### 步骤 1: 成本计算模块（1小时）

**文件**：`token_cost_calculator.py`

功能：
1. 基于价格和使用量计算成本
2. 对比不同模型的成本效益
3. 生成成本趋势图数据

#### 步骤 2: HTML 展示（1小时）

新增卡片：**💰 Token 成本分析**
