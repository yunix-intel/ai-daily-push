## ⚠️ 技术要点

### 全文翻译
1. **内容获取**
   - 使用 BeautifulSoup 解析
   - 提取正文内容（去除广告、导航）
   - 处理不同网站的结构差异

2. **翻译优化**
   - 分段翻译（避免 token 限制）
   - 保留标题、段落格式
   - 处理特殊符号和代码

3. **缓存策略**
   - URL hash 作为文件名
   - JSON 存储（原文+译文+元数据）
   - 过期时间：7天

### 影响分析
1. **分析维度**
   - 影响程度（量化）
   - 影响方向（明确）
   - 受影响行业（具体）
   - 时间跨度（清晰）

2. **策略整合**
   - 优先级：重大事件 > 常规分析
   - 风险提示：突发事件风险置顶
   - 操作建议：结合事件影响
